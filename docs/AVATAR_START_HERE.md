# Webot robot

Aria's human avatar has been replaced with the same robot and animation code from the previous `Webot_Chatbot_Complete.zip`.

The main chatbot retains the current pr-10 layout, controls, input and speech behavior. The new robot adds its entrance, idle/thinking motion, speaking movement and 1.3-second goodbye. Its smile stays fixed, with no lip-sync.

Run instructions are in `../README.md`. The independent robot preview is available at `http://localhost:5173/avatar-preview.html` while the frontend runs. Its included English, Hindi and Gujarati recordings do not require the backend.
